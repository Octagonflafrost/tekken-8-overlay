## 🧩 About

**Tekken 8 Overlay** is a comprehensive overlay for Tekken 8 featuring frame data display, combo trials, hitbox viewer, move list, and practice mode enhancements.

Based on popular tools like **Tekken Overlay**, **TekkenBot**, and **Frame Whisperer**.

---

## ✨ Features

### 🎮 Core Features
- Frame Data Display — show startup, block, hit frames in real-time
- Combo Trials — interactive combo challenges with timing feedback
- Hitbox Viewer — visualize character and attack hitboxes
- Move List — overlay with full move properties and punishers
- Practice Mode Tools — infinite health, reset positions, dummy control

### 🎨 Visual & UI
- Customizable Overlay — adjust position, scale, and transparency
- Input Display — show directional inputs and button presses
- Damage Numbers — display damage values during combos
- Color-Coded Frames — quick reference for advantage/disadvantage

### 🏋️ Training & Analysis
- Punishment Trainer — practice punishing unsafe moves
- Frame Trap Guide — learn frame advantage situations
- Matchup Notes — save notes per character
- Replay Analysis — overlay during replay mode
